## 说明

- 仅记录**项目特定**约定，不记录语言通用规范
- 用户明确纠正过的做法优先记录
- 适用性与冲突处理遵循 [policy.md](policy.md)

## 写入格式

字段和操作规则见 [policy.md](policy.md)。以下仅为格式示例。

```markdown
## YYYY-MM-DD 一句话约定标题
<a id="conv-YYYYMMDD-01"></a>

- **状态**：有效
- **范围**：适用模块 / 路径 / 文件类型
- **来源**：用户确认日期与内容 / 项目规范链接
- **标签**：#module-name #style
- **约定**：具体规则
- **理由**：为什么这么定
- **反例**：错误写法示范（可选）
- **正例**：正确写法示范
```
