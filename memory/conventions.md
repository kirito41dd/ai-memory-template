## 说明

- 仅记录**项目特定**约定，不记录语言通用规范
- 用户明确纠正过的做法优先记录
- 与通用规范冲突时，项目约定优先

## 写入格式

```
## YYYY-MM-DD 一句话约定标题

- **约定**：具体规则
- **理由**：为什么这么定
- **反例**：错误写法示范（可选）
- **正例**：正确写法示范
- **范围**：影响哪些模块 / 文件类型
```
