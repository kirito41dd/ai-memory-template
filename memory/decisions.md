## 写入格式（ADR 风格）

字段和操作规则见 [policy.md](policy.md)。以下仅为格式示例。

```markdown
## YYYY-MM-DD 一句话决策标题
<a id="dec-YYYYMMDD-01"></a>

- **状态**：有效
- **范围**：适用模块 / 路径 / 版本条件
- **来源**：用户确认日期与内容 / 设计文档 / PR 链接
- **标签**：#module-name #architecture
- **背景**：为什么需要做这个决策
- **选项**：考虑过哪些方案（A/B/C）
- **决策**：最终选择的方案
- **理由**：为什么选这个，放弃其他的原因
- **落地**：待实施 / 试验中 / 已实施
```
