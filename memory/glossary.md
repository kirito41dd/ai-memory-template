## 写入格式

字段和操作规则见 [policy.md](policy.md)。术语名作标题，日期单独记录；以下仅为格式示例。

```markdown
## 术语名（缩写）
<a id="term-YYYYMMDD-01"></a>

- **状态**：有效
- **范围**：适用业务域 / 模块
- **来源**：用户确认日期与内容 / 业务文档链接
- **标签**：#module-name #business
- **定义**：一句话解释
- **上下文**：在什么场景下使用
- **相关**：关联的其他术语 / 模块 / 文件
- **首次出现**：YYYY-MM-DD
```
