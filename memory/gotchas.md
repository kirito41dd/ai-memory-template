# 踩坑与注意事项

<!-- SUMMARY
覆盖范围：非显而易见的 bug、易犯错误、隐藏依赖
-->

## 写入格式

字段和操作规则见 [policy.md](policy.md)。以下仅为格式示例。

```markdown
## YYYY-MM-DD 一句话坑点标题
<a id="got-YYYYMMDD-01"></a>

- **状态**：有效
- **范围**：适用模块 / 路径 / 依赖版本
- **来源**：复现方式与验证结果 / 修复 commit / Issue 链接
- **标签**：#module-name #error-type
- **现象**：表现出的错误行为
- **原因**：根本原因
- **解决**：如何修复（优先文件路径 + 符号名，必要时附 commit，行号仅供辅助）
- **避免**：将来如何避免（检查清单 / 约定）
```
