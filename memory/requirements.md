## 写入格式

字段和操作规则见 [policy.md](policy.md)。以下仅为格式示例。

```markdown
## YYYY-MM-DD 一句话标题
<a id="req-YYYYMMDD-01"></a>

- **状态**：有效
- **范围**：适用模块 / 路径 / 版本条件
- **来源**：PRD / Issue 链接，或用户确认日期与内容
- **标签**：#module-name #feature
- **内容**：需求描述
- **原因**：为什么新增或调整，哪些内容不在范围内
- **进展**：设计中 / 实施中 / 已完成
- **相关**：文件路径 / commit / PR 链接
```
